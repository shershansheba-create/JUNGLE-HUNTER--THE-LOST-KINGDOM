# JUNGLE-HUNTER--THE-LOST-KINGDOM
🏹 Jungle Hunter – The Lost Kingdom
🌴 A 2D Jungle Adventure Game Built with Python and Pygame

Welcome to Jungle Hunter – The Lost Kingdom! An exciting 2D adventure game where you play as a brave hunter exploring a mysterious jungle, fighting dangerous enemies, collecting treasures, and discovering a hidden ancient temple.

🎮 About the Game

The hunter enters a mysterious jungle on a mission to discover the Lost Kingdom. Along the journey, the player must collect golden coins, find five magical blue crystals, defeat wild creatures using arrows, and reach the ancient temple to complete the mission.

✨ Features
🌳 Jungle-themed gaming environment
🏹 Custom hunter character
🦖 Moving enemy creatures
🎯 Bow and arrow shooting system
🪙 Golden coin collection
💎 Five magical crystal collection
❤️ Three-life health system
⭐ Score tracking system
🏛️ Ancient temple mission
⏸️ Pause and resume option
🏆 Victory and Game Over screens
🕹️ Game Controls
Key	Function
ENTER	Start Game
LEFT ARROW	Move Left
RIGHT ARROW	Move Right
A / D	Move Left / Right
SPACE	Jump
X	Shoot Arrow
P	Pause / Resume
R	Restart Game
ESC	Exit Game
🛠️ Technologies Used
Python – Main programming language
Pygame – Game development library
Pygame Rect and Collision Detection – Player and enemy interactions
Pygame Drawing Functions – 2D graphics and environment
🚀 Installation and Execution
Step 1: Install Python

Download Python from: https://www.python.org/downloads/

Step 2: Install Pygame

Open your terminal and execute:

bash
pip install pygame

Step 3: Download the Project

Clone the repository:

bash
git clone YOUR_GITHUB_REPOSITORY_URL


Or download the ZIP file from GitHub.

Step 4: Run the Game

Open the project folder and execute:

bash
python jungle_hunter.py
